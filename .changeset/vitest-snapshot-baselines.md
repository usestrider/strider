Add `SnapshotBaseline.toMatch`, which compares a `Uint8Array`, such as `page.pdf()`'s bytes, with a baseline file named with its own extension (`"invoice.pdf"`). A `.png` name is compared by pixels with the `threshold`, `maxDiffPixels`, and `maxDiffPixelRatio` options and defaults of `ScreenshotBaseline.toMatch`; any other extension, JPEG included, is compared byte for byte. Baselines are keyed by test file, name, browser engine, and platform at `__baselines__/<test file>/<name without extension>-<browser>-<platform>.<extension>` beside the test file, a directory Vitest never writes to, and follow the same update modes as screenshots: a local run writes a missing baseline and still fails, `vitest -u` rewrites differing ones, and CI writes none, though a mismatch still writes its failure files. A mismatch fails with `SnapshotBaselineError` and writes the actual and expected files, plus a diff image for a PNG, under `.vitest-snapshots/`; images are attached to the test. `SnapshotBaseline.CurrentSettings` overrides the update mode, the baseline path, and the output directory. Text keeps Vitest's own `toMatchFileSnapshot`. `ScreenshotBaseline` is unchanged.
