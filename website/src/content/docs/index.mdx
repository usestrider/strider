Strider is browser automation for [Effect](https://effect.website). It speaks each browser's protocol directly,
with no driver in between: the Chrome DevTools Protocol, WebDriver BiDi and WebKit's own.

**Status:** pre-release. The API works on Chromium, Firefox and WebKit, and can still change before 1.0. What a
browser can't do fails with `Unsupported`, naming the capability.

```ts
import { Browser, Expect } from "@usestrider/browser"
import { Chromium } from "@usestrider/browser/chromium"
import { Effect } from "effect"

const program = Effect.scoped(Effect.gen(function*() {
  const page = yield* Browser.newPage()
  yield* page.goto("https://shop.example.com")
  yield* page.getByRole("button", { name: "Add to cart" }).click()
  yield* page.getByText("1 item").pipe(Expect.toBeVisible)
})).pipe(Effect.provide(Chromium.layer({ executablePath: "/usr/bin/chromium" })))
```

A launch runs the executable you name; Strider never finds or installs a browser. `npx strider browsers` lists the
browsers on your machine.

## How it works

Pages, locators, `click`, `fill` and retrying expectations work much as in Playwright. What differs:

- **Lifetimes are scopes.** A page, route or dialog handler ends with the `Scope` that acquired it, even on failure
  or interruption.
- **Subscribe, then act.** To catch a popup, download or response an action causes, subscribe first. A subscription
  sees events after it starts, never before.
- **Errors say what happened.** Each module has one error, whose `reason` says why and whose `hint` says what to do,
  such as `Another element covers the element's action point: div.toast "Saved"`. Any operation can also fail with
  `TargetGone` or `Timeout`, both in its type.
- **One deadline per operation,** covering everything it does. `Deadline.within("5 seconds")` sets one for a block.
- **Access is typed.** A page you opened is a `Page`. An attached browser's tab is observed until you ask for access,
  and acting on a read-only page doesn't compile.
- **Nothing is implicit.** No hidden sleeps, grace periods or retries of input that may have reached the page.
