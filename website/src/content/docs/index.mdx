Strider is browser automation for [Effect](https://effect.website): scripts, tests and agents that drive Chromium,
Firefox or WebKit. It speaks each browser's protocol directly, so it drives browsers as they're installed, with no
driver or patched build beside them.

Strider is pre-release; the API can still change before 1.0. What a browser
[can't do](/docs/browsers/choosing#capabilities) fails with `Unsupported`, naming the capability.

```ts
import { NodeServices } from "@effect/platform-node"
import { Browser, Expect } from "@usestrider/browser"
import { Chromium } from "@usestrider/browser/chromium"
import { Effect, Layer } from "effect"

const BrowserLive = Chromium.layer({ executablePath: "/usr/bin/chromium" }).pipe(
  Layer.provide(NodeServices.layer)
)

const program = Effect.scoped(Effect.gen(function*() {
  const page = yield* Browser.newPage()
  yield* page.goto("https://shop.example.com")
  yield* page.getByRole("button", { name: "Add to cart" }).click()
  yield* page.getByText("1 item").pipe(Expect.toBeVisible)
})).pipe(Effect.provide(BrowserLive))
```

A launch runs the executable you name; Strider never finds or installs a browser.
[`npx strider browsers`](/docs/installation#a-browser) lists the browsers on your machine.

## Differences from Playwright

Pages, [locators](/docs/pages/locators), [`click` and `fill`](/docs/pages/actions) and
[retrying expectations](/docs/pages/expectations) work much as in Playwright. What differs:

- **Lifetimes are scopes.** A page, [route](/docs/events/routes) or [dialog handler](/docs/events/kinds#dialogs-and-file-choosers)
  ends with the `Scope` that acquired it, even on failure or interruption.
- **Subscribe, then act.** To catch a popup, download or response an action causes,
  [subscribe first](/docs/events/events). A subscription sees events after it starts, never before.
- **[Errors](/docs/errors) say what happened.** Each module has one error, whose `reason` says why, with a `hint`
  of what to do, such as `2 elements match and 1 of them is visible; add .filter({ visible: true })`. A failed
  expectation has the values it saw instead. Any operation can also fail with `TargetGone` or `Timeout`, both in
  its type.
- **[One deadline](/docs/deadlines) per operation,** covering everything it does.
  `Deadline.within("5 seconds")` sets one for a block.
- **[Access is typed.](/docs/pages/attaching#access-levels)** A page you opened is a `Page`. A tab of a browser you
  attached to can only be watched until you ask for access, and acting on it before then doesn't compile.
- **Nothing is implicit.** No hidden sleeps, grace periods or retries of input that may have reached the page.
