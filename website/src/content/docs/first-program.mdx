## The whole program

Open a shop, add a product to the cart, and check the cart says so:

```ts title="checkout.ts"
import { NodeRuntime, NodeServices } from "@effect/platform-node"
import { Browser, Expect } from "@usestrider/browser"
import { Chromium } from "@usestrider/browser/chromium"
import { Config, Effect, Layer } from "effect"

const program = Effect.scoped(Effect.gen(function*() {
  const page = yield* Browser.newPage()
  yield* page.goto("https://shop.example.com")
  yield* page.getByRole("button", { name: "Add to cart" }).click()
  yield* page.getByText("1 item").pipe(Expect.toBeVisible)
  yield* Effect.log(`Added to the cart on "${yield* page.title}"`)
}))

const BrowserLive = Chromium.layerConfig({
  executablePath: Config.String("CHROMIUM_PATH")
}).pipe(Layer.provide(NodeServices.layer))

program.pipe(Effect.provide(BrowserLive), NodeRuntime.runMain)
```

```sh
CHROMIUM_PATH=/usr/bin/chromium node checkout.ts
```

## Opening a page

`Browser.newPage()` makes a fresh context, with its own cookies and storage, and a page in it. Both close when
the `Scope` from `Effect.scoped` ends: on success, failure or interruption.

`page.goto(url)` returns when the navigation commits, which is when it has succeeded or failed.
`{ waitUntil: "load" }` waits for the load too. A 404 still commits: `goto` returns the navigation, with its
response.

## Locators and actions

`page.getByRole("button", { name: "Add to cart" })` is a locator: how to find an element, not the element. It
finds the element again each time it's used, so it survives a re-render.

`click()` waits until exactly one element matches and it's visible, enabled, still and uncovered, scrolling it into
view, then clicks once. If something covers it as the click is sent, the page never sees the click and the action
checks again. [Actions](/docs/pages/actions) lists each action's checks.

## Expectations

`Expect.toBeVisible` checks now and on each change to the page, until it passes or the deadline does. It's the
program's only waiting: no sleeps.

`locator.pipe(Expect.toBeVisible)` and `Expect.toBeVisible(locator)` are the same. Matchers with arguments are dual:
`locator.pipe(Expect.toHaveText("1 item"))` or `Expect.toHaveText(locator, "1 item")`.

## Reads

`page.title` is a read: an `Effect` that reads the title when it runs, never waiting or retrying. Actions are
calls, reads are values, and only `Expect.to*` retries.

## The layer

`Chromium.layerConfig` launches the executable `CHROMIUM_PATH` names, headless, with a temporary profile;
`NodeServices.layer` lets it start the process. When the program ends, the browser exits and the profile is
deleted. `NodeRuntime.runMain` turns Ctrl-C into an interruption, which closes the page and the browser.

To run on another browser, change the layer.

## Steps as functions

Write steps with `Effect.fn`. The name becomes the step's span, so a trace shows `addToCart` with its clicks
inside.

```ts title="checkout.ts"
import { Browser, Expect, Page } from "@usestrider/browser"
import { Effect } from "effect"

const addToCart = Effect.fn("addToCart")(function*(page: Page.Page, product: string) {
  const card = page.getByRole("article").filter({ hasText: product })
  yield* card.getByRole("button", { name: "Add to cart" }).click()
  yield* page.getByRole("status").pipe(Expect.toContainText(product))
})

const checkout = Effect.fn("checkout")(function*(page: Page.Page) {
  yield* page.getByRole("link", { name: "Cart" }).click()
  yield* page.getByRole("button", { name: "Check out" }).click()
  yield* page.pipe(Expect.toHaveURL(/\/checkout$/))
})

const program = Effect.scoped(Effect.gen(function*() {
  const page = yield* Browser.newPage()
  yield* page.goto("https://shop.example.com")
  yield* addToCart(page, "Field guide to herons")
  yield* checkout(page)
}))
```

A step that takes the page works the same in a script, a test or a `strider` segment. One that only reads can
take a `Page.ReadonlyPage`, and then also works on pages you may only inspect.

## Many pages at once

Run steps concurrently with Effect. Each `newPage` gets its own context, so the pages share no cookies:

```ts
import { Browser } from "@usestrider/browser"
import { Effect } from "effect"

const title = Effect.fn("title")(function*(url: string) {
  const page = yield* Browser.newPage()
  yield* page.goto(url)
  return yield* page.title
}, Effect.scoped)

const titles = Effect.fn("titles")(function*(urls: ReadonlyArray<string>) {
  return yield* Effect.forEach(urls, title, { concurrency: 4 })
})
```
