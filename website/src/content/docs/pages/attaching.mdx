title: Attached browsers

A launch starts a new browser. To drive one that a person or another program already has running, with its
sessions and tabs as they are, attach to it; it keeps running after.

## Connecting

`layerConnect` takes the browser's debugging address. Chrome opens its debugging port when started with one, and
a profile of its own ([Chromium](/docs/browsers/chromium#attaching) says why):

```sh
google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-debug
```

`browser.pages` is the browser's open tabs, a [`Watchable`](/docs/pages/expectations#watchables) read as
`page.url` is. You didn't open them, so they're observed, and `inspect` takes read access
([Access levels](#access-levels)):

```ts
import { NodeSocket } from "@effect/platform-node"
import { Browser, Page } from "@usestrider/browser"
import { Chromium } from "@usestrider/browser/chromium"
import { Effect, Layer } from "effect"

const Attached = Chromium.layerConnect("http://127.0.0.1:9222").pipe(
  Layer.provide(NodeSocket.layerWebSocketConstructor)
)

const describeTab = Effect.fn("describeTab")(function*(tab: Page.ObservedPage) {
  const inspected = yield* tab.inspect
  return { url: yield* tab.url, title: yield* inspected.title }
})

const openTabs = Effect.fn("openTabs")(
  function*() {
    const browser = yield* Browser.Browser
    return yield* Effect.forEach(yield* browser.pages, describeTab)
  },
  Effect.scoped,
  Effect.provide(Attached)
)
```

- [`Firefox.layerConnect`](/docs/browsers/firefox#attaching): Firefox's remote agent.
- [`Bidi.layerConnect`](/docs/api/browser/bidi/Bidi#layerConnect): any WebDriver BiDi endpoint.
- [`WebKit.layerAttach`](/docs/browsers/webkit#attaching): a WebKitGTK or WPE browser's inspector server. Its pages
  can be read and navigated, not typed into.

## Access levels

A tab you didn't open may be in use, by a person or another program, and a stray click or route there changes
what they see. Take `inspect` when the program only reads, so acting on the tab doesn't compile, and `control`
when it must act. A page has one of three types:

| Type                | Can                                                                            |
| ------------------- | ------------------------------------------------------------------------------ |
| `Page.ObservedPage` | report its state and [events](/docs/events/events)                             |
| `Page.ReadonlyPage` | also locate and read, take [snapshots](/docs/agents/snapshots) and screenshots, and [evaluate](/docs/pages/expectations#evaluating-in-the-page) in isolation |
| `Page.Page`         | also act, navigate, evaluate among the page's own scripts, and declare [routes](/docs/events/routes) |

A page you opened is a `Page`; one you didn't, such as an attached browser's tab or a launched browser's first
tab, is observed. Access lasts for the scope `inspect` or `control` is called in.
[`browser.defaultContext`](/docs/pages/contexts#logging-in-once), a context you didn't make, takes `control` the
same way.

An observed tab reports its URL, so a program can find the tab it wants before taking access. With `control`, it
can add a [route](/docs/events/routes), which answers the tab's matching requests itself: `Route.abort()` fails
them, and `hits` counts them, so a step can wait until one was blocked:

```ts
import { Browser, Page, Route } from "@usestrider/browser"
import { Console, Effect, Option } from "effect"

const findTab = Effect.fn("findTab")(function*(origin: string) {
  const browser = yield* Browser.Browser
  for (const tab of yield* browser.pages) {
    if ((yield* tab.url).startsWith(origin)) return Option.some<Page.ObservedPage>(tab)
  }
  return Option.none<Page.ObservedPage>()
})

const blockAnalytics = Effect.fn("blockAnalytics")(function*() {
  const found = yield* findTab("https://app.example.com")
  if (Option.isNone(found)) return
  const tab = yield* found.value.control
  const blocked = yield* tab.route(
    "**/analytics/**",
    () => Effect.succeed(Route.abort())
  )
  yield* tab.getByRole("button", { name: "Refresh" }).click()
  yield* blocked.hits.waitFor((count) => count > 0)
  yield* Console.log("Blocked the refresh's analytics call")
}, Effect.scoped)
```

- When the scope closes, the route is removed and the tab stays open. Using `tab` again fails with
  [`TargetGone`](/docs/api/browser/Target#TargetGone), reason `AccessReleased`.
- A helper that only reads can take a `Page.ReadonlyPage`, so it works on an inspected tab and on a `Page`
  alike:

```ts
import { Expect, Page } from "@usestrider/browser"
import { Effect } from "effect"

const unreadCount = Effect.fn("unreadCount")(function*(page: Page.ReadonlyPage) {
  const messages = page.getByRole("list", { name: "Inbox" }).getByRole("listitem")
  yield* messages.first.pipe(Expect.toBeVisible)
  return yield* messages.filter({ hasText: "Unread" }).count
})

const unreadInTab = Effect.fn("unreadInTab")(function*(tab: Page.ObservedPage) {
  return yield* unreadCount(yield* tab.inspect)
})
```
