# Vendored: effect-jsdocs

`Jsdocs.ts` and `bin.ts` are Effect's JSDoc checker, `packages/tools/jsdocs/src` in
[Effect-TS/effect](https://github.com/Effect-TS/effect) at commit `93abf0208` (2026-10-19), copied unchanged
under Effect's MIT license (`LICENSE` here). Effect keeps the tool private, so it isn't on npm.

To update it, copy both files from a newer Effect commit and record that commit here. Don't edit them in place:
the point is to hold our JSDoc to exactly the contract Effect holds its own to.
